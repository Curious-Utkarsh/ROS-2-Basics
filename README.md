# ROS 2 Learning Workspace (2024)

My ROS 2 learning workspace from August–November 2024, kept as a record of how I learned the core concepts. Most packages follow course exercises; the small projects at the end are my own extensions.

| Area | Packages |
|---|---|
| Core concepts | `my_py_pkg`, `my_cpp_pkg`, `my_robot_interfaces` — publishers, subscribers, services, custom interfaces, parameters |
| Advanced concepts | `actions_py_pkg`, `lifecycle_py`, `executors_py`, `components_py` |
| TurtleSim projects | `my_turtle_project`, `my_turtle_bot`, `my_robot_bringup` — including "Catch Them All" |
| Simulation projects | `my_prius` + `prius_logic` (camera lane following), `my_rover` + `rover_logic` (obstacle avoiding, edge avoiding, wall following, ArUco detection), `nav2_py`, `opencv_py` |
| Perception | `aruco_pose_estimation`, `aruco_interfaces` |
